## 商标词排查

### 快速与逐词排查

1. 进入「商标词排查」，选择快速排查。粘贴品牌或 Listing 标题，按页面支持录入其他文本。
2. 核对命中词对应品牌字段、标题还是其他文本。查看商标状态、风险说明以及与 TRO 的关联。`TM` 等状态也需要结合最新记录和商品类目判断。
3. 暂停使用待核词，核对品牌名、所有者、类目、市场和授权文件。合法兼容说明与品牌字段的判断口径可能不同。用真实通用属性修正标题后复查。
4. 整理逐词结果。一次词命中是候选线索，需检查目标商品与权利记录是否相关。

### Excel / CSV 批量排查

1. 选「批量排查」，下载该入口的模板，或上传页面接受的 Excel / CSV。常见列为 SKU、品牌、标题、五点、详情。先从几行试导入并核对映射。
2. 确认原始序号和 SKU 一一对应。把商品 ID、GTIN、SKU 设为文本，避免前导零丢失或长编号变成科学计数法。按页面预览头数、选项、价格和行数提交。
3. 等到任务完成再看报告和导出。逐行处理缺列、空标题、解析失败、无命中和命中。若开启图片或合规增量维度，分别确认执行范围和费用。
4. 在带有「AI 改写」入口的结果中，用标题、品牌、五点、描述及已核实风险词生成候选文案。人工确认规格、尺寸、兼容性和认证陈述，然后复查。文案生成后仍需按原工作流保存或上架。

免费版支持快速和批量商标词排查、TRO 律所地址查询、白名单及插件商标排查。可试用或显示锁定的功能，以及账号、次数和能否上传，以免费版页面和实际权限为准。 [免费版入口](https://safesellai.com/freeAI/)

## Listing 安全性多维评分

1. 输入 Amazon / Walmart 商品链接、ASIN 或 Item ID，检查识别的平台和商品。网页读取使用正常连接的 SafeSell AI 插件。
2. 基础评分综合标题、品牌、关键词、TRO 及能读取并处理的图片文字或图形商标。勾选需要的「图片版权比对」「外观专利图搜」「发明专利（文字）」或「平台合规」，并选择平台规则。页面的基础和图片预计消耗须分开核对。
3. 选择「开始评分」。插件在商品核心字段可读后提交，可复用已打开的同款商品。Walmart 要求人机验证时，用提示里的链接到商品页正常完成，再回工作台。提取失败停在提交前，评分未开始。
4. 看总分、商品 ID、风险地图、标题命中、图片逐张结果、修改建议与相应证据。对图片限定为已分析数，对专利、版权与合规查看实际执行状态。
5. 如果网页仍提示旧版插件等待整页超时，核对官网与商店当前版本，再更新插件。不要反复按评分按钮。 [插件更新与安装](store-plugin.md)

### 一次排查多条商品链接

1. 在网页启用链接排查入口后，选择批量模式。按一行一个粘贴链接、有效 ASIN 或 Walmart Item ID，也可点击「下载链接模板」后通过 Excel 导入。
2. 导入前检查链接列、行序号、平台及商品 ID。提交量以页面标注为准。先用一小批核对插件能否取得正确标题、品牌、五点和详情。
3. 查看逐条状态及可用的导出。抓取失败、部分执行及需要人工验证的行分别记下，复跑前确认原任务和流水。批量链接排查的实际维度以当前页面返回为准。

## TRO 案件和地址

### TRO 案件排查

1. 进入「TRO 排查 → TRO 案件排查」，使用品牌或页面支持的案件线索查询。品牌拼写变体可分开查。
2. 展开案件，抄录案号、法院、原告、律所、日期、来源和相关产品。把同名、同律所或同类商品的线索保留为待核。
3. 查看诉状、证据附件、拟议命令和已签署文书，核对覆盖主体、商品、时点和范围；进一步区分案件相关性、权利状态、平台投诉和账户资金措施。
4. 上游不可用、没有检索结果、案件存在和实际覆盖该商品分别记录。涉及止付、投诉、下架或申诉时，保存平台原通知和订单资料。 [案件资料与运营指引](https://safesellai.com/guides)

### TRO 律所下单地址黑名单与 F6

- 免费版入口可查询系统及当前账号可见的律所地址记录。使用完整地址、门牌、单元、城市、州、邮编核对；有多个匹配时检查来源。
- 正式版在「TRO 排查 → TRO下单地址黑名单监控」查看 F6 配置、地址和命中记录。具有相应权限时可维护自有地址记录及查看分页。确认店铺、最新同步和匹配状态。
- 地址相似只能触发复核。保留来源、命中字段和处置人，导出时对实际收件地址脱敏。取消订单、发货或标记客户使用各自的授权流程。

## 专利排查

| 需求 | 模式 | 操作与核对 |
|---|---|---|
| 图搜外观候选 | 外观专利排查 | 上传清晰商品图，选择准确品类，必要时加产品词和状态筛选。按当前页面支持切换单张或表格批量。 |
| 关键词或专利号 | 专利词 / 描述排查 | 输入英文产品名、功能结构、行业同义词或完整公开号。按实际法域、类型、状态查看结果与数据来源。 |
| 已有候选号 | 指定专利比对 | 输入需要核对的专利号，上传商品图，查看对应专利附图、视角与同异点，再回原始记录。 |
| 涉诉专利线索 | 专利及 TRO 结果中的案件入口 | 核对是否同号、同一权利和同一商品，区分专利是否存在、是否有效与是否进案件。 |

- 外观可用正面、侧面、斜视、白底及不同背景分别查，保留图之间的产品对应。仅改背景、裁切或色彩会影响检索结果。
- 发明或实用专利看权利要求和方案结构。文字匹配和相似图都是找候选的依据。状态和期满日期仍需核对官方记录。
- 文献统计、文字索引和图片向量索引的覆盖不同；补入记录可能先供文字查。报告写上本次使用的资料源、法域、图像角度、状态过滤和未覆盖部分。 [专利与版权资料](https://safesellai.com/guides)

## 图片版权和图形标

1. 进入「产品图版权检查」。单张精查适合看权利方、视觉命中、参考图和案号。批量检测适合先筛一组图，使用当前页面接受的格式，先确认预览、序号和原文件名。
2. 同时记录图片中的文字、图形商标、水印、版权图像匹配和 TRO 证据图各自是否执行与命中。回到实际图片逐张核对，检查不同视角和裁剪方式。
3. 核对权利方、素材来源、授权链、参考图和相关案件。未收录参考图的资料无法参加视觉检索。未命中只描述本次已执行且已覆盖的库。需要明细时用单张精查复核。
4. 批量回收结果时以「文件名 + 上传顺序 + 原图 + 每张状态」关联。按实际页面显示核对扣费、成功数、失败数与跳过数。关页或中断后先查询批量任务状态或历史。
5. MCP `check_image` 属于图片文字、图形商标和 TRO 初筛。版权查图走版权功能，外观查图走专利功能。若对合法可改素材使用图片识别或去 LOGO，仍须保留素材授权和修改记录，去除标识不能产生授权。 [图片隐私与数据说明](https://safesellai.com/extension-privacy.html)

### 批量图片 LOGO 识别与授权素材处理

1. 有相应权限时打开「批量图片 LOGO 识别 + 一键去 LOGO」。可直接传图，或下载 Excel 模板并填入图片 URL 列。
2. 先识别并查看命中位置，逐图选择允许修改的区域。图案、商标、文字和非目标内容分别核对，确认素材授权范围。
3. 核对实际处理对象与预计费用，再对已选图片执行修改。比较前后结果，按权限下载。通过 Excel 处理时核对输出新列、原行、处理状态和单图扣费。
4. 编辑后复查素材。图片处理完成不能证明取得商标、外观或版权授权。REST 用户在对应公开接口中核对本功能的文件和计费要求。 [开发者与 REST 接口](api-xiaoan.md)

## 平台违禁品检查与词库

- 合规检查先选实际销售平台和站点，单品可提交标题、品牌、描述，批量时用该入口的 Excel 模板，导入后核对商品字段与行映射。核对品类、限制类型、适用市场、认证材料和规则版本。名称相似、材质或年龄段不清时回看商品实物及平台现行规则。
- 修改黑白名单前确认当前账号、词的完整拼写、适用品牌和授权。记录生效范围，保存后重跑已知样本。白名单用于有依据的豁免，避免用竞争店铺品牌或敏感通用词扩大豁免。
- 页面及套餐变动时，以当前操作入口、实际输出和流水为准。 [官方知识中心](https://safesellai.com/guides)
