# 店铺体检、运营与浏览器插件

[SafeSell AI 正式工作台](https://safesellai.com/app/) · [安装指引](https://safesellai.com/install) · [多店铺和体检资料](https://safesellai.com/guides)

## 店铺管理与授权

1. 登录后进「店铺体检 → 店铺管理」。核对主账号或子账号、店铺名称、平台和站点。只选择当前页面实际支持的平台及授权方式。
2. 选择绑定方式。通过官方授权或平台提供的接口凭证连接；在平台侧只授予执行任务需要的权限。在 SafeSell AI 的绑定表单填写，避免把密钥、令牌或完整授权截图交给 AI 聊天。
3. 检查绑定状态，跑一次商品或绩效读取确认店铺、站点和响应。遇到过期、权限不足、未绑定、店铺为空区分处理。需要重新授权时用原有正确店铺，避免重复创建绑定。
4. 主账号按工作台的企业授权范围查看本团队的子账号或指定店铺。子账号各自隔离，权限以实际可见店铺和菜单为准。子账号上架或查看权限要用对应账号复核。解除绑定、删除子账号和改权限按已确认范围执行并读回。

## 全店体检怎么用

### 侵权体检

1. 在「店铺体检」选择已绑定店铺。先选小批量或页面允许的范围，核对预计 SKU 数和 S算力。全店大批量任务需要足够余额。
2. 保留基础商标排查，按需要选择平台合规、图片识别、版权或专利等页面实际可用维度。查描述和五点时核对当前授权返回的字段是否齐全，缺字段的维度单独标记。
3. 启动体检后记录任务、店铺和运行时间，查看进度、历史或已完成报告。逐项复核命中 SKU、问题位置、原因和建议，再按页面权限导出或进行单品深查。
4. 修正商品文本或素材后按约定范围复查，保留基线与变化。只汇报实际分析或成功读取的 SKU。权限不足或服务繁忙时先看任务是否已建立及是否已扣费。

### 体检历史、报告与深度分析

- 在「历史体检记录」按店铺和时间打开已保存的结果。连接中断时优先从原记录读回，核对体检编号、完成状态、分析的 SKU 数与费用。
- 根据报告显示的按钮下载 PDF 或 HTML、导出 Excel，或生成商标标注表。核对文件中的店铺、风险词、商品和字段。部分报告入口依账号、站点和具体体检结果开放。
- 需要复核高风险 SKU 时，进入当前结果下的「AI 深度分析」或相应复核入口。先核对样本、费用和已完成维度，保留 AI 提示所引用的实体或证据。

### 店铺绩效、监控和自动体检

| 模块 | 用法 |
|---|---|
| 账号健康与绩效 | 打开所选平台的绩效或账号健康面板，核对店铺、指标统计区间和样本量。按面板查看订单取消、准时发货、有效追踪、准时送达、退货或投诉，并与平台卖家后台核实。 |
| 经营诊断 | 有授权时查看已有的经营概览、成本与费用、结算、订单或商品数据。区分销售额、净结算和利润，按店铺、站点、币种和时间对比。缺成本或缺账单标记待核。 |
| 定时体检 | 对指定店铺打开「每日自动体检」或相应选项，核对显示的时间、范围、扣费及余额不足行为。首次自动运行后回看历史和下一次计划。 |
| 店铺监控 | 在「店铺监控」中选择受支持的绑定店，开启或立即检测，检查最近一次扫描、警报和证据。自动监控与单次体检各有状态。 |
| 通知与 F6 | 调整前核对消息类型、店铺、接收渠道和已开启的规则，分别验证改后的目标告警和相邻业务提醒。涉诉地址监控查看真正命中、来源和复核状态。 |

涉及经营数据导出时按权限脱敏订单地址、客户联系方式及凭证。给报告保留统计日期及数据来源。后台监控、消息通知和收款提醒分别按其配置处理。

## 匹配上架、选品库和运营写入

1. 有授权且能看到「匹配上架」时，选择目标店铺。可从插件商品页、卖家店铺或可用的批量入口采集条目。核对商品 URL、Item ID、规格、变体、GTIN 和计划 SKU。
2. 导入前看重复商品、关联变体、缺失标识及已有店铺报价。选品库中保留所需条目，跟卖筛查发现的风险进入复核。
3. 对每个拟上架条目回到商标、TRO、版权、外观专利和平台合规的证据。对 GTIN 的自动回填状态、来源和精确对应单独核实。
4. 执行前预览店铺、商品、SKU、价格、库存及风险确认。获得上架、批量改价、改库存、归档或下架的对应授权后再提交。
5. 保存任务、Feed 或状态 ID，查询处理结果及平台实际目录和报价。待处理或网络中断说明仍待核，查到前一次结果后再补做失败项。 [平台与多店铺工作流](https://safesellai.com/guides)

### 选品库归档、批量调整与 AI 智能跟

- **归档和恢复。** 从选品库把暂不处理的商品移到「归档库」。恢复时先查目标商品、SKU、当前状态和重复条目，再选「恢复到选品库」。查看移入和恢复后的实际列表。
- **定向批量改价、库存与导出。** 勾选商品，核对目标店铺及仓库，按页面支持选定改动与是否推送。导出 Excel 时确认仅勾选商品或全库范围。执行后分别读回 SafeSell AI 和平台状态。
- **AI 智能跟。** 页面显示该权限时，可按商品与店铺配置价格上下限、检查周期和执行时段，实际可选的自动补库存也在各自规则中核对。开启前确认目标、价格区间、库存策略和用户授权。开启后检查实际执行记录。

## Chrome / Edge 插件

### 安装与更新

- **商店安装。** 用电脑打开[官方商店条目](https://chromewebstore.google.com/detail/elnbimbljajfmnobhedlcmifdikflknh)，在 Chrome 添加，或在 Edge 允许其他商店的扩展后添加。固定到工具栏。
- **官网下载手动安装。** 从[官方安装页](https://safesellai.com/install)取当前 ZIP。解压，进入 `chrome://extensions` 或 `edge://extensions`，开启开发者模式，「加载已解压的扩展程序」，选包含 `manifest.json` 的目录。使用工作环境允许的安装方式。
- **版本和切换。** 商店和官网下载可能处在不同审核或发布阶段。分别核对浏览器扩展页及[官网下载版本接口](https://safesellai.com/api/extension/version)。更换安装方式时确认只有一个 SafeSell AI 扩展在启用，更新后刷新工作台和商品页。

### 登录和操作

| 场景 | 步骤 |
|---|---|
| 商品页单品排查 | 打开受支持的真实商品详情，允许插件访问该站点，登录 SafeSell AI。在插件「单品排查」核对标题、品牌、商标与 TRO 输出及可用的图片能力。 |
| 页面风险标注 | 在正常商品页检查命中词在标题、品牌和其他内容中的位置。打开对应明细，核对命中解释与来源。 |
| 网页链接和批量检查 | 在 SafeSell AI 页面允许插件运行，进入 Listing 评分或相关批量入口。插件从选定商品页提取字段。商品信息不足、验证码、版本较旧和权限不足按实际报错处理。 |
| 跟卖筛查和采集 | 有权限时打开受支持的 Walmart 搜索页、类目页或卖家店铺页，查看采集进度与范围。翻页、可用的自动翻页、批量筛选、GTIN 补全和 CSV 导出使用当前插件提供的操作。对每条保留 Item ID 和状态，采购或上架另按其授权执行。 |
| 加入选品库与变体 | 按插件内授权入口核对选定商品和变体，核实已写入的条目、是否重复及是否仍待识别 GTIN，再进入后续工作台功能。 |
| 辅助店铺体检 | 对授权店铺用插件对应入口进行商品提取或店铺体检，检查店铺、页面授权、任务或报告状态及数据覆盖。 |

遇到「Walmart 要求人机验证」时在正常商品页手动完成，再回工作台。识别失败先确认商品页可打开、扩展已启用、当前站点获准访问、账号状态有效。网页后台与插件的会话状态分别核对。插件只读排查、配置改动和业务写入的操作范围不同。 [插件隐私政策](https://safesellai.com/extension-privacy.html)
